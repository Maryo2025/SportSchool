SPORTSCHOOL — Mini Escuela Deportiva

Versión 1 funcional y gratuita.
- Abre index.html para probarla.
- Los datos se guardan en el navegador (localStorage).
- Incluye notas, promedios, exámenes, anotaciones, asistencia, estadísticas, logros y perfil.
- Desde Perfil puedes exportar/importar los datos en JSON.
