SPORTSCHOOL — Mini Escuela de Gimnasia y Deportes

Incluye en una sola versión:
- Roles Profesor/Estudiante
- Notas de 1.0 a 10.0
- 4 períodos académicos
- Pesos (%) y promedios ponderados
- Exámenes creados por el profesor
- Preguntas de selección múltiple, V/F y respuesta escrita
- Temporizador opcional
- Enlaces para compartir exámenes
- Resultados de exámenes integrados al libro de calificaciones
- Anotaciones, asistencia, estadísticas, logros y perfil
- Exportación de datos; importación solo para profesor

La versión local usa localStorage. Para seguridad real entre dispositivos y para que el estudiante no pueda modificar datos ni manipulando el navegador, hay que conectar Supabase con RLS y autenticación antes de usarla como sistema real.
